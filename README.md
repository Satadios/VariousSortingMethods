# Various Sorting Methods 
### by Satadios


This repository is intended for studying various types of sorting, their complexity and execution time. 

# About

This project was completed as a laboratory work for the course "Software Engineering and Computer Science" at Tomsk State University.


## Types of sorting that will be discussed:
  * simplest sort
  * Exchange sort
  * Sorting by inserts
  * Sorting by selection
  * Merge sort
